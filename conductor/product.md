# Product Definition: SDD-Crash-Course Playground & CoursePulse Capstone

## Vision
Provide a self-contained, hands-on engineering playground for mastering Spec-Driven Development (SDD), Conductor, OpenSpec, and Spec-as-Single-Source-of-Truth (`SPEC.md`).

## Target Personas
1. **Software Engineering Students & Practitioners**: Learning how to move from unconstrained "Vibe Coding" to deterministic, test-verified Spec-Driven Development.
2. **Staff / Principal Engineers**: Adopting Dual-Engine SDD (`OpenSpec` capability deltas + `Conductor` TDD tracks + `SPEC.md` clean-room rebuild testing) on production brownfield codebases.

## Core Capabilities
- **Lab 01**: Greenfield Distributed Rate Limiter (`rate-limiter` capability).
- **Lab 02**: Brownfield Distributed Lease Lock Manager (`lease-manager` capability with fencing tokens).
- **Lab 03**: Stateful Circuit Breaker (`circuit-breaker` capability with `CLOSED -> OPEN -> HALF_OPEN` state machine).
- **Lab 04**: Token Bucket Quota Allocator (`quota-allocator` capability with 5-Step Brownfield Scorecard Refactoring).
- **Lab 05**: Thread-Safe Key-Value Cache (`kv-cache` capability with SDD Code Review & Stacked PR Task Decomposition).
- **Lab 06**: CoursePulse Enrollment & Waitlist Service (`SPEC.md` 8-Section SSOT & Clean-Room Rebuild Test).

# Milestone 1 (M1 — Greenfield Core Ledger) Design Spec
**Date:** 2026-10-01
**Status:** Implemented

## Overview
Implement `LedgerFlow`, the greenfield core multi-currency ledger supporting account creation, balance inquiry, and single-currency transfers with a flat 1% platform fee and threshold-based settlement (`SETTLED` vs `PENDING`).

## Requirements & Design

### 1. Account Creation (`open_account`)
- **Signature:** `open_account(account_id: str, currency: str = 'USD', initial_cents: int = 0) -> dict`
- **Rules:**
  - `account_id`: Trimmed non-empty string (`account_id.strip()`). Duplicate `account_id` raises `ValueError`.
  - `currency`: Uppercase 3-letter currency in `{'USD', 'EUR', 'GBP'}`. Invalid currency raises `ValueError`.
  - `initial_cents`: Integer `>= 0`. Negative or non-integer raises `ValueError`.
  - Returns account dictionary containing `account_id`, `currency`, `balance`, and `balance_cents`.

### 2. Balance Inquiry (`get_balance`)
- **Signature:** `get_balance(account_id: str) -> int`
- **Rules:**
  - Returns the current integer balance in cents for `account_id`.
  - Raises `KeyError` if `account_id` does not exist.

### 3. Transfer Execution (`post_transfer`)
- **Signature:** `post_transfer(tx_id: str, from_acct: str, to_acct: str, amount_cents: int, timestamp: int) -> dict`
- **Validation:**
  - Raises `KeyError` if `from_acct` or `to_acct` is unknown.
  - Raises `ValueError` if `from_acct == to_acct`, `amount_cents <= 0`, currency mismatch between `from_acct` and `to_acct`, invalid/duplicate `tx_id`, or insufficient funds (`balance < amount_cents + fee_cents`).
- **M1 Fee & Settlement Rules:**
  - Platform fee: `fee_cents = amount_cents // 100` (flat 1%).
  - Immediate debit from `from_acct`: `amount_cents + fee_cents`.
  - If `amount_cents > 100000`: `status = 'PENDING'` (`to_acct` is not credited yet).
  - If `amount_cents <= 100000`: `status = 'SETTLED'` (`to_acct` is credited with `amount_cents` immediately).

# Milestone 4 (M4 — Reversals & Constitutional Scope Governance) Design Spec
**Date:** 2026-10-04
**Status:** Implemented

## Overview
Extend `LedgerFlow` with transfer reversals (`reverse_transfer`), platform fee accounting (`total_collected_fees`), and strict non-overdraft guarantees.

## Requirements & Design

### 1. Transfer Reversal (`reverse_transfer`)
- **Signature:** `reverse_transfer(tx_id: str) -> dict`
- **Rules:**
  - Raises `KeyError` if `tx_id` is unknown.
  - Raises `ValueError` if the transfer status is already `'REVERSED'`.
  - If `status == 'AWAITING_CLEARING'`:
    - Refunds `amount_cents + fee_cents` back to `from_acct` (`to_acct` was never credited).
    - Sets `status = 'REVERSED'`.
  - If `status == 'SETTLED'`:
    - Checks if `to_acct` has `balance >= amount_cents`. If `to_acct` balance `< amount_cents`, raises `ValueError('Recipient has insufficient funds to reverse')` without mutating any state.
    - Otherwise debits `amount_cents` from `to_acct`, refunds `amount_cents + fee_cents` to `from_acct`, and sets `status = 'REVERSED'`.
  - Returns a copy of the updated transfer dictionary.

### 2. Platform Fee Accounting (`total_collected_fees`)
- **Signature:** `total_collected_fees(currency: str = 'USD') -> int`
- **Rules:**
  - Validates `currency` against supported currencies (`USD`, `EUR`, `GBP`).
  - Sums `fee_cents` across all transfers in that `currency` whose status is `'SETTLED'` or `'AWAITING_CLEARING'` (excluding `'REVERSED'`).

### 3. Overdraft Prohibition
- `post_transfer` strictly prohibits overdrafts (`from_acct` balance `< amount_cents + fee_cents` raises `ValueError`).

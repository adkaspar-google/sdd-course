2. VERBAL SCRIPT

Why does conversational Vibe Coding break down on real projects? Because chat prompts disappear as soon as a pull request merges. Without a durable specification, an AI agent silently guesses edge cases—like whether blank task titles are allowed or whether an exact 100 percent time budget should be rejected—and writes sycophantic tests that rubber-stamp broken code. Specificational Coding flips the workflow: the engineer edits and approves a persistent specification artifact, and the agent compiles that spec into production code and one-to-one traceable tests, governed by Karpathy's four rules: Think Before Coding, Simplicity First, Surgical Changes, and Goal-Driven Execution.
